Описание проекта: 
Разработка десктопного приложения на C# (WPF) для управления учебным процессом 
Проект состоит из двух взаимосвязанных модулей, работающих с единой базой данных

МОДУЛЬ №1 УПРАВЛЕНИЕ ПРЕПОДАВАТЕЛЯМИ И РАСПИСАНИЕМ

1. Сетка расписания:
Отображение пар по дням недели часам и неделям в виде таблицы (DataGrid) 
Нужно реализовать фильтры по дням, чтобы преподаватель видел только свои занятия

2. Назначение занятий:
Возможность добавить пару и привязать к ней преподавателя, предмет, время и аудиторию (данные аудиторий берутся из второго модуля)

3. Статусы занятий:
Быстрая отметка состояния пары: проведена (зеленая галочка)
или отменена (красный крестик)

5. Учет рабочего времени:
Автоматический подсчет академических часов.
Система суммирует часы только тех пар которые отмечены галочкой (проведены)
Отмененные пары в расчет не идут

6. Отметка отсутствий:
- Фиксация присутствия преподавателя на паре
- Календарь отсутствий: выходной, отпуск, больничный (с указанием категории)
- Логика: если у преподавателя стоит отпуск или больничный, система блокирует возможность поставить его на пару в эти дни

6. Интерфейс и визуализация:
- Автоматическое присвоение уникального цвета каждому предмету для удобства чтения сетки
- Цветовая подсветка выставленных оценок (например, красный для неудовлетворительных, зеленый для отличных)
- Отдельная вкладка с общим списком всех преподавателей и их текущим статусом (Работает / В отпуске / На больничном)
- (Cделать все максимально оптимизировано и удобно в использовании)

МОДУЛЬ №2. УПРАВЛЕНИЕ АУДИТОРИЯМИ

1. Реестр аудиторий:
Список всех кабинетов с указанием их вместимости и оборудования (проектор, компьютеры и т.д.)

2. Расписание аудиторий:
Сетка занятости кабинетов по дням и часам (кто и когда там проводит пару)

3. Контроль конфликтов:
Защита от двойного бронирования. Система не должна давать поставить две разные пары в один кабинет в одно и то же время

ТЕХНОЛОГИИ:
- Язык: C#
- Платформа: WPF (десктопное приложение)
- База данных: SQL Shell(psql) (локальное хранение данных).
